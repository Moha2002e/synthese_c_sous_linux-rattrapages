CONNEXION/DÉCONNEXION ET AUTHENTIFICATION

🎯 Objectif de cette étape

Cette étape implémente la gestion des connexions clients et l'authentification des utilisateurs dans le système maraîcher en ligne. Elle établit les fondations de la communication client-serveur.

📈 PARCOURS UTILISATEUR COMPLET

1. Lancement et connexion

  • Utilisateur lance ./Client
  • Application envoie CONNECT au serveur
  • Serveur enregistre PID dans table connexions
  • Fenêtre client s'affiche

2. Authentification

  • Utilisateur saisit nom/mot de passe
  • Clic sur "Login"
  • Envoi LOGIN au serveur
  • Serveur vérifie dans clients.dat
  • Si OK : création processus Caddie + réponse positive
  • Si KO : réponse négative avec message d'erreur
  • Interface se met à jour (loginOK() ou message d'erreur)

3. Déconnexion

  • Clic sur "Logout" ou croix de fenêtre
  • Si utilisateur connecté : envoi LOGOUT
  • Serveur nettoie table connexions
  • Envoi DECONNECT
  • Terminaison processus client

🎯 SYNTHÈSE FINALE

Cette étape établit les fondations de la communication client-serveur avec :

  • Gestion des connexions : Enregistrement/désinscription des clients
  • Authentification robuste : Vérification utilisateurs existants/nouveaux
  • Architecture multi-processus : Création dynamique des caddies
  • Gestion des ressources : Nettoyage propre à la fermeture
  • Interface utilisateur : États connecté/déconnecté bien définis

Le code implémente fidèlement la spécification avec une architecture robuste permettant la gestion de 6 clients simultanés maximum, chaque client ayant son propre processus caddie dédié.
