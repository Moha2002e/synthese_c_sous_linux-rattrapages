```cpp // 52 caractères : 51 caractères + '\0' char *pShm; // Pointeur vers la mémoire partagée // Format : [caractères...]['\0'] // Exemple : " Bienvenue sur le site du Maraicher en ligne ! \0" ```

Gestion des signaux

```cpp // Publicite - Masquage des signaux sauf SIGUSR1 sigset_t mask; sigfillset(&mask); sigdelset(&mask,SIGUSR1); sigprocmask(SIG_SETMASK,&mask,NULL); // Client - Armement SIGUSR2 struct sigaction B; B.sa_handler = handlerSIGUSR2; sigemptyset(&B.sa_mask); B.sa_flags = 0; sigaction(SIGUSR2,&B,NULL); ```

📈 PARCOURS UTILISATEUR COMPLET

1. Démarrage du système

  • Serveur démarre
  • Création mémoire partagée (52 caractères)
  • Lancement processus Publicite
  • Initialisation publicité "Bienvenue..."
  • Début boucle de rotation

2. Connexion d'un client

  • Client se connecte (CONNECT)
  • Attachement mémoire partagée en lecture seule
  • Armement signal SIGUSR2
  • Réception immédiate des publicités

3. Affichage publicité en temps réel

  • Publicite envoie UPDATE_PUB au serveur
  • Serveur envoie SIGUSR2 à tous les clients
  • Clients lisent mémoire partagée
  • Affichage publicité dans interface
  • Rotation d'un caractère vers la gauche
  • Attente 1 seconde
  • Répétition

4. Fermeture du système

  • CTRL-C sur serveur
  • Handler SIGINT
  • Envoi SIGINT au processus Publicite
  • Suppression mémoire partagée
  • Nettoyage ressources
