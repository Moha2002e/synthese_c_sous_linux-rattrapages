📋 SYNTHÈSE COMPLÈTE - ÉTAPE 5

ACHATS D'ARTICLES ET MISE À JOUR DU PANIER

🎯 Objectif de cette étape

Cette étape implémente le système d'achat d'articles et la gestion du panier client. Elle permet aux clients d'acheter des articles, de mettre à jour les stocks en base de données, et de visualiser leur panier d'achat.

🔄 Architecture du système d'achat

📊 ANALYSE DU CODE IMPLÉMENTÉ

1. Client - Envoi requête ACHAT

```cpp // Client - Envoi ACHAT void WindowClient::on_pushButtonAcheter_clicked() { char tmp[5]; sprintf(tmp, "%d", getQuantite()); requete = constructeurRequete(5, 1, getpid(), ACHAT, articleEnCours.id, tmp, nullptr, nullptr, 0.0); msgsnd(idQ, &requete, sizeof(MESSAGE) - sizeof(long), 0); } ```

2. Client - Réception réponse ACHAT et envoi CADDIE

```cpp // Client - Réception résultat void receptionArticle(MESSAGE* m) { int tmp = atoi(m->data3); if (tmp == 0) { w->dialogueMessage("Achat", "Stock insuffisant !"); } else { sprintf(tmpbuffer,"%d unité de %s acheté avec succés", tmp, articleEnCours.intitule); w->dialogueMessage("Achat", tmpbuffer); // Envoi CADDIE pour mise à jour panier requete = constructeurRequete(3, 1, getpid(), CADDIE,0,nullptr,nullptr,nullptr,0.0); msgsnd(idQ, &requete, sizeof(MESSAGE) - sizeof(long), 0); w->videTablePanier(); totalCaddie = 0.0; } } ```

3. Caddie - Gestion des requêtes ACHAT et CADDIE

```cpp // Caddie - Stockage article void stockeArticle(MESSAGE* pM) { if(atoi(pM->data3) != 0) { // Achat réussi if (nbArticles >= 10) { fprintf(stderr, "Erreur : le tableau d'articles est plein.\n"); exit(1); } articles[nbArticles].id = pM->data1; strcpy(articles[nbArticles].intitule, pM->data2); articles[nbArticles].prix = pM->data5; articles[nbArticles].stock = atoi(pM->data3); strcpy(articles[nbArticles].image, pM->data4); nbArticles++; } } ```

4. AccesBD - Traitement requête ACHAT

```cpp // AccesBD - Gestion achat int requeteAchatArticle(int id, int quantite) { ARTICLE tmp = requeteSqlArticle(id); int articlesDecrementes = 0; if (tmp.stock >= quantite) { int nouveauStock = tmp.stock - quantite; sprintf(requete, "UPDATE UNIX_FINAL SET stock = %d WHERE id = %d;", nouveauStock, id); if (mysql_query(connexion, requete) != 0) { fprintf(stderr, "Erreur de mise à jour du stock: %s\n", mysql_error(connexion)); return 0; } articlesDecrementes = quantite; } return articlesDecrementes; } ```

2. Stockage d'article dans le Caddie

```cpp // Caddie - Stockage article void stockeArticle(MESSAGE* pM) { if(atoi(pM->data3) != 0) { // Achat réussi if (nbArticles >= 10) { fprintf(stderr, "Erreur : le tableau d'articles est plein.\n"); exit(1); } articles[nbArticles].id = pM->data1; strcpy(articles[nbArticles].intitule, pM->data2); articles[nbArticles].prix = pM->data5; articles[nbArticles].stock = atoi(pM->data3); strcpy(articles[nbArticles].image, pM->data4); nbArticles++; } } ```

3. Mise à jour du panier client

sequenceDiagram participant C as Client participant S as Serveur participant Ca as Caddie C->>S: CADDIE S->>Ca: CADDIE Ca->>Ca: envoiArticleVecteur() loop Pour chaque article du vecteur Ca->>C: Article (data1=id, data2=intitule, data3=quantité, data5=prix) Ca->>C: SIGUSR1 C->>C: ajouteArticleTablePanier() C->>C: totalCaddie += prix * quantité C->>C: setTotal(totalCaddie) end
```cpp // Caddie - Envoi articles du panier void envoiArticleVecteur(MESSAGE* pM) { for(int i = 0; i < nbArticles; i++) { pM->type = pidClient; pM->expediteur = getpid(); pM->data1 = articles[i].id; strcpy(pM->data2, articles[i].intitule); pM->data5 = articles[i].prix; sprintf(pM->data3, "%d", articles[i].stock); strcpy(pM->data4, articles[i].image); msgsnd(idQ, pM, sizeof(MESSAGE) - sizeof(long), 0); kill(pidClient, SIGUSR1); } } // Client - Réception articles panier case CADDIE: w->ajouteArticleTablePanier(m.data2, m.data5, atoi(m.data3)); totalCaddie = totalCaddie + (m.data5 * atoi(m.data3)); w->setTotal(totalCaddie); break; ```

4. Gestion des stocks en base de données

graph TD A[Requête ACHAT] --> B[requeteSqlArticle] B --> C[SELECT stock FROM UNIX_FINAL] C --> D{stock >= quantité ?} D -->|Oui| E[UPDATE stock = stock - quantité] D -->|Non| F[Pas de modification] E --> G[articlesDecrementes = quantité] F --> H[articlesDecrementes = 0] G --> I[Retour quantité achetée] H --> I
```cpp // AccesBD - Gestion achat int requeteAchatArticle(int id, int quantite) { ARTICLE tmp = requeteSqlArticle(id); int articlesDecrementes = 0; if (tmp.stock >= quantite) { int nouveauStock = tmp.stock - quantite; sprintf(requete, "UPDATE UNIX_FINAL SET stock = %d WHERE id = %d;", nouveauStock, id); if (mysql_query(connexion, requete) != 0) { fprintf(stderr, "Erreur de mise à jour du stock: %s\n", mysql_error(connexion)); return 0; } articlesDecrementes = quantite; } return articlesDecrementes; } ```

📈 PARCOURS UTILISATEUR COMPLET

1. Sélection et achat d'article

  • Client consulte article (CONSULT)
  • Client sélectionne quantité
  • Clic sur "Acheter"
  • Envoi ACHAT(id, quantité) au serveur
  • Transfert vers Caddie
  • Envoi via pipe vers AccesBD

2. Traitement de l'achat

  • AccesBD vérifie stock disponible
  • Si suffisant : UPDATE stock = stock - quantité
  • Si insuffisant : Pas de modification
  • Retour quantité réellement achetée
  • Réponse vers Caddie

3. Stockage et notification

  • Caddie reçoit réponse
  • Si achat réussi : stockeArticle() dans vecteur
  • Transmission résultat au client
  • Client affiche message de succès/échec

4. Mise à jour du panier

  • Si achat réussi : client envoie CADDIE
  • Client vide table panier et totalCaddie
  • Caddie envoie tous les articles du vecteur
  • Client reconstruit affichage panier
  • Calcul et affichage nouveau total
